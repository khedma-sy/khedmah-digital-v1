# Backend Shared Foundation

This folder contains Mission 052 shared technical foundation types only.

Implemented foundation files:

- `common-types.mjs` provides technical enums/helpers for visibility, lifecycle status, generic result objects, and paginated result objects.

Shared code must remain technical and domain-neutral. Business logic, business entities, user models, service models, organization models, ownership rules, trust decisions, verification decisions, marketplace behavior, payment behavior, ranking behavior, AI decisions, and tracking behavior must not be placed in shared code.

Mission 052 does not implement product features, API routes, database access, authentication, authorization, frontend code, UI screens, or production infrastructure.
