# OP-003B Canonical Operational Adapters Foundation

This foundation binds a Business Request to canonical OP-001A Registration, OP-001B Verification, and immutable OP-001C Decision references. Adapters validate lineage and supply the existing OP-001D/OP-002A input shapes; they do not implement registration, verification, Decision, governance, or downstream business rules.

Adapter lifecycle is `CREATED → VALIDATED → BOUND`. No policy/role resolver, persistence, API, UI, workflow/runtime engine, ranking, Discovery/Search change, or new business capability exists here.
