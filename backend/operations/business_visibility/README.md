# OP-002C Business Visibility Capability

This bounded capability determines whether a canonically published Business is policy-eligible to be `VISIBLE` or `HIDDEN`. It records governance, canonical associations, and audit evidence only.

It defines neither public representation nor public fields. It contains no Public Business Profile, discovery, search, ranking, recommendations, marketplace, reviews, messaging, booking, payments, notifications, workflow or runtime orchestration, AI decisions, persistence, API, UI, database, or network behavior.
