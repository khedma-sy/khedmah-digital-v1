# OP-002F Business Search Capability

This bounded capability finds only an OP-002E `DISCOVERABLE` Business backed by matching Public Profile, `VISIBLE`, and `PUBLISHED` records. Search results reuse only the canonical OP-002D projection.

The query, eligibility record, and result contract are independent of candidate retrieval so a future authorized provider may optimize retrieval without changing the Search model. No cache, index, optimization algorithm, ranking, recommendation, personalization, AI/ML, maps, reviews, messaging, booking, payments, notifications, API, UI, persistence, database, network, or runtime orchestration exists here.
