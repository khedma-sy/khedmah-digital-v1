# Contributing

## Contribution Principles

- Keep changes aligned with approved Khedmah Digital V1 documentation.
- Protect Arabic-first product direction and V1 scope.
- Do not introduce product features, APIs, database models, migrations, or frontend screens without an approved implementation mission.
- Keep future modules documented only until governance approves activation.

## Documentation Standards

- Use Markdown.
- Keep links repository-relative.
- Avoid secrets, credentials, tokens, and production URLs.
- Update affected governance, product, architecture, contract, and operations documents together when terminology changes.
