# Responsibility Matrix

## Governance Responsibilities

| Area | Responsibility |
| --- | --- |
| Product scope | Define and protect approved V1 boundaries. |
| Architecture | Maintain system direction without premature implementation. |
| Domain contracts | Define approved domain terminology, relationships, lifecycle, and validation expectations. |
| Operations | Define completion and safety expectations. |
| Vision | Preserve Arabic-first business growth platform strategy and brand direction. |

## Implementation Boundary

No party should implement backend, frontend, API, database, infrastructure, or product feature work without an approved implementation mission.
