# جرد واجهات «خدمة» — Web وAndroid

تاريخ الجرد: 2026-08-26. المرجع: `main@3a401ecc7c3e3460e3e02d07da853607ef7c7041`.

## نتيجة التشريح

- Web يحتوي 34 ملف صفحة و3,177 أسطر صفحات.
- CSS العام موزع على `globals.css` (991 سطراً)، `brand-system.css` (362)، و`home.module.css` (229).
- توجد قواعد داكنة/زرقاء قديمة وأسماء مثل `auth-phone` و`map-phone` و`catalog-phone` داخل الطبقة العامة.
- عدد كبير من الصفحات يعتمد `style={{...}}` وألواناً مباشرة، لذلك لا يتبع نظام تصميم واحداً.
- Android يضع التنقل والمصادقة والرئيسية والبحث والخريطة في `MainActivity.kt` واحد (222 سطراً)، مع رموز نصية بدل مجموعة أيقونات.
- لا توجد حالياً بنية كاملة للصفحة الحية، الإعلانات المرتبطة بالأنشطة، الأسئلة الشائعة، السياسات، الإشعارات أو إعدادات الحساب.

## التصنيف

الحالات:

- **إعادة بناء**: المسار صحيح وظيفياً لكن بنيته البصرية أو المعمارية لا تحقق النظام المعتمد.
- **تحسين**: قابل للاحتفاظ بعد نقله إلى القالب المشترك.
- **تحويل قديم**: يحتفظ به مؤقتاً للتوافق، ولا يُعرض في التنقل أو خريطة الموقع.
- **حذف/دمج**: واجهة أو مفهوم مكرر يجب ألا يبقى كمنتج مستقل.
- **جديد**: غير موجود ويلزم إنشاؤه.
