# RP39 — KORA Executive Admin UI ownership bridge

## Decision

The supervised KORA Executive Admin OS is owned by the exact Web page below while the primary Site Atlas is reconciled with the recovered KORA operations module and the approved Product V2 administration surfaces.

This is a **narrow bridge, not a general documentation waiver**. It authorizes no wildcard admin route family, no automatic execution authority, no Production action, and no replacement for the primary Site Atlas.

## Exact page owner

- KORA Executive Admin OS: [`apps/frontend/app/admin/kora/page.tsx`](../../apps/frontend/app/admin/kora/page.tsx)

## Boundary

KORA may read explicitly sourced operational metrics, expose telemetry gaps, evaluate supplied UI evidence, review confirmed process-local incidents, draft advisory admin tasks, and run Executive / Expose / KillCritic / Autopsy modes. Drafted tasks are not durable execution jobs and are always `autoExecutable=false` in this slice.

The page links only to administration routes that exist in the current runtime. Taxi Pricing and Billing are labelled API-ready/UI-pending until their visual administration pages are separately implemented and reviewed.

The supplement does not authorize Production deployment or bypass build, test, Preview, authorization, audit, or explicit release gates.
