## التنفيذ الحالي

- إنشاء مكتبة SVG موحدة للأيقونات المعتمدة.
- إنشاء مكوّن رابط/إجراء موحد بحالات hover وpress وfocus واستجابة الموبايل.
- حقن أيقونات البحث، اكتشاف الخدمات، إنشاء الحساب، الدخول، والخروج.
- إضافة loading وerror آمنين لتسجيل الخروج ومنع تكرار الطلب.
- إزالة تسمية «انضم كشريك» المكررة واستبدالها بالفعل القانوني «إنشاء حساب».
- دعم `prefers-reduced-motion` في الأزرار والأيقونات.

## KILLCRITIC

لم تُحقن أزرار طلب الخدمة والرسائل والتقييم والمحفظة والطلبات والإشعارات والحملات وروابط الإحالة والدفع، لأنها لا تملك قدرات V1 معتمدة. إظهارها كأزرار حية سيخلق وظائف ميتة أو يوسع النطاق دون عقود وصلاحيات وبيانات.
