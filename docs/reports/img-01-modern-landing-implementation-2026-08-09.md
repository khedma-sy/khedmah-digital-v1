# IMG-01 — تنفيذ الصفحة الأولى الحديثة

## القرار

أعيد تعريف الصورة المرفقة كمرجع بصري للصفحة الأولى، لا كلقطة واجهة تُعرض حرفياً. استُخدم الجزء الفني (المظلة وخريطة سوريا) كأصل بصري محسّن للويب، بينما أصبحت العناوين والأزرار عناصر HTML حقيقية ومتجاوبة.

## الهيكل المحقون

1. رسم المظلة وخريطة سوريا: WebP مضمن كنص في `lib/brand-hero-image.ts` لتجاوز قيود دمج الملفات الثنائية.
2. العنوان: «خدمة ديجتل» HTML قابل للقراءة والفهرسة والتكبير.
3. العبارة: «تحت مظلة واحدة» HTML.
4. «ابدأ الآن»: رابط فعلي إلى `/service-catalog`.
5. «إنشاء حساب»: رابط فعلي إلى `/auth/register`.
6. «تسجيل الدخول»: رابط فعلي إلى `/auth/login`.

## معالجة الصورة

- مصدر الإدخال: الصورة المرفقة من مالك المنتج.
- اقتص الجزء الفني فقط حتى لا تتكرر النصوص والأزرار المرسومة داخل الصورة.
- التحويل: PNG 1254×1254 إلى WebP فني 1254×825 بجودة 88.
- الحجم الثنائي الأصلي: نحو 135KB، ثم ضُمّن Base64 في ملف TypeScript نصي لأن أداة الدمج لا تدعم binary patches.
- لا يحتوي الأصل المستخدم في runtime على أزرار وهمية قابلة للالتباس.

## البريد

خدمة البريد غير مفعلة حسب توجيه مالك المنتج. لذلك لا يوجد زر بريد أو newsletter أو استعادة عبر البريد في الصفحة الأولى. تفعيل البريد مهمة لاحقة بعقد مستقل.

## الاستجابة

- Desktop: عمود فني وعمود محتوى وإجراءات.
- Mobile/Tablet: الرسم كاملاً أولاً ثم النصوص والأزرار دون قص.
- الصورة تستخدم `object-fit: contain` ولا تستخدم `cover`، لذلك لا تقص المظلة أو الخريطة.
- الأزرار HTML وليست مناطق نقر فوق صورة.

## بوابة القبول

- الرسم كامل بلا قص.
- لا تكرار للنص أو الأزرار داخل raster.
- الروابط الثلاثة تقود إلى مسارات موجودة.
- دعم RTL وfocus وreduced motion.
- نجاح اختبارات frontend وNext.js build.
