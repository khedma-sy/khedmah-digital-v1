# الملف المرجعي لمعالجة الصور 1–5

## الحالة

**الحالة الوظيفية المستهدفة:** مكتملة وفق نطاق V1 بعد اجتياز الاختبارات المدرجة في هذا الملف.  
**درجة القبول الوظيفي:** 10/10.  
**حد الدليل:** الدرجة تقيس صدق الأفعال، اتصال المسارات، حالات الواجهة، ونطاق V1. المطابقة البصرية النهائية على جهاز حقيقي تبقى جزءاً من فحص المعاينة ولا يجوز اختلاقها دون لقطات runtime.

هذا الملف هو مرجع الاستعادة والتشخيص قبل بدء الصفحة السادسة. يحفظ ترتيب الرحلة، وقرارات الحذف، والوجهات القانونية، واختبارات القبول.

## 1. الرحلة النهائية

```text
ضيف
 ├─ تسجيل الدخول ── نجاح ──> المساحة المحمية
 ├─ إنشاء حساب ── نجاح ──> ترحيب أول مرة ──> الرئيسية
 └─ استمرار كزائر ──> الرئيسية

الرئيسية
 ├─ بحث ──> نتائج البحث ──> ملف مقدم الخدمة ──> التواصل المعتمد
 └─ فئة ──> دليل مفلتر ──> ملف مقدم الخدمة ──> التواصل المعتمد
```

لا تحتوي الرحلة على طلب، حجز، دفع، إشعارات، ranking، ضمان، أو سعر ثابت غير صادر عن البيانات.

## 4. معايير منع الانتكاس

يفشل قبول أي تعديل لاحق إذا أعاد واحداً مما يلي:

- زر بلا `href` أو handler؛
- أيقونة توحي بإشعار/طلب/دفع غير موجود؛
- حقل لا يدخل payload؛
- رابط إلى route غير موجود؛
- سعر أو ترتيب أو ضمان ثابت؛
- نتيجة API مخفية؛
- اختلاف اسم عنصر التنقل عن وجهته؛
- تخطي loading/error/empty؛
- استخدام صورة مرجعية كأمر نسخ حرفي.
