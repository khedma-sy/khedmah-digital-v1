# Operations Product Live Certification Package

This package implements Board decision `BOD-EXEC-2026-005`. Live evidence must be collected only in the approved production environment with `OPERATIONS_APPROVED_PRODUCTION=true`. Runtime evidence is deliberately Git-ignored and must be attached through the Board-approved restricted evidence channel; no token, secret payload, production URL, log payload, or IAM member identity belongs in Git.
